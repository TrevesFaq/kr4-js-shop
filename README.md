# Retro Shelf — КР №4

Интерактивная версия магазина из КР №3.
Тема: JavaScript, DOM, события и валидация формы.

## JavaScript-файлы

- `js/data.js` — массив из 11 товаров.
- `js/main.js` — общие функции сайта, меню и карусель.
- `js/catalog.js` — генерация карточек, поиск, фильтр и сортировка.
- `js/validation.js` — проверка формы заявки.

## Реализовано

- Карточки товаров создаются через `createElement()`.
- Поиск работает по названию товара.
- Каталог фильтруется по категории и сортируется.
- При отсутствии результатов показывается сообщение.
- Форма проверяет имя, e-mail, телефон, выбор товара и согласие.
- Текстовые данные выводятся через `textContent`.

## JavaScript

- `js/data.js` содержит объект учебного товара.
- `js/main.js` содержит функции форматирования цены, расчёта скидки и определения наличия товара.
- На главной странице результат выводится через `textContent`.

## Практическая работа №16

- Создан массив `products` из 11 товаров магазина.
- Добавлены поиск по названию и `id`, фильтр по категории и сортировка по цене.
- Реализованы подсчёт общей стоимости, количества товаров в наличии и средней цены.
- Результаты проверяются в консоли и выводятся на страницу через `textContent`.

## Практическая работа №17

- Созданы `js/catalog.js` и `js/validation.js`.
- Карточки каталога создаются JavaScript-кодом через `createElement()`.
- Поиск, фильтр категории и сортировка обновляют каталог.
- Если товары не найдены, показывается пустое состояние.
- Ошибки формы выводятся на страницу через `textContent`.
- Текстовые данные не вставляются через `innerHTML`.
