# Контрольная работа №4 — Retro Shelf

**Тема:** «Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта».

Проект — адаптивная версия учебного магазина ретро-консолей. Он продолжает HTML/CSS-проект из КР №1. Bootstrap не используется.

## Страницы проекта

- `index.html` — главная страница, популярные товары и карусель.
- `catalog.html` — каталог с фильтром и карточками товаров.
- `product.html` — карточки товаров и таблицы характеристик.
- `order.html` — форма заявки.
- `contacts.html` — контактная информация.

## JavaScript

- `js/data.js` содержит объект учебного товара.
- `js/main.js` содержит функции форматирования цены, расчёта скидки и определения наличия товара.
- На главной странице результат выводится через `textContent`.

## Практическая работа №16

- Создан массив `products` из 11 товаров магазина.
- Добавлены поиск по названию и `id`, фильтр по категории и сортировка по цене.
- Реализованы подсчёт общей стоимости, количества товаров в наличии и средней цены.
- Результаты проверяются в консоли и выводятся на страницу через `textContent`.
